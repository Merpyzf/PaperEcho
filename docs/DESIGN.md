# 纸间书摘 × M5Paper 书摘回顾系统

## Context

纸间书摘 (XMNote) 是一款 Android 读书笔记应用，用户希望在 M5Paper 墨水屏上实现"书摘回顾"功能：
- M5Paper 运行 HTTP Server，纸间书摘 App 通过局域网推送书摘数据
- M5Paper 本地存储数据到 SD 卡，以纯文字极简风格展示书摘
- 当前阶段仅实现 M5Paper 端，Android 端后续开发，先用 curl 测试

已有基础：TextReader 控件（分页、触摸翻页、横竖屏切换）、SD 卡 TTF 字体加载。

## 整体架构

```
┌─────────────────┐     HTTP POST      ┌─────────────────────┐
│  纸间书摘 App   │ ──────────────────→ │     M5Paper         │
│  (Android)      │   /api/sync         │                     │
│                 │   JSON + 书摘数据   │  WiFi + HTTP Server │
└─────────────────┘                     │  SD 卡存储          │
                                        │  墨水屏展示         │
                                        └─────────────────────┘
```

### 状态机

```
BOOT
  ├─ 初始化 SD / 字体
  ├─ 读取 /xmnote/wifi.json
  │   ├─ 无配置 → WIFI_SETUP
  │   └─ 有配置 → 尝试连接
  │       ├─ 成功 → HOME
  │       └─ 失败 → WIFI_SETUP
  │
WIFI_SETUP（触摸交互）
  ├─ 扫描 WiFi 列表 → 用户点选
  ├─ 触摸键盘输入密码
  ├─ 连接成功 → 保存配置 → HOME
  │
HOME（状态屏）
  ├─ 显示: IP 地址、书摘数量、同步提示
  ├─ HTTP Server 后台运行，接收数据
  ├─ 有书摘时显示 "开始阅读" 按钮 → READING
  ├─ 长按中键 → WIFI_SETUP（重新配网）
  │
READING（书摘浏览）
  ├─ 纯文字极简展示，每屏一条书摘
  ├─ 左右滑动 / 按键翻页
  ├─ 按中键 → 返回 HOME
```

```
└──────────────────────────────────────────┘
```

**键盘规格（540px 宽度）：**
- 左右边距 20px，可用宽度 500px
- 每键宽 48px，间距 2px → 10 键正好 500px
- 键高 56px，行间距 4px → 4 行共 240px
- 键盘区域 Y 起始: 960 - 240 - 20(底部边距) = 700px

**键盘状态切换：**
- 默认小写字母
- 点击 `⇧` → 切换大写（单次），再点回小写
- 点击 `123` → 切换数字/符号层: `1234567890` / `@#$_&-+()` / `!'"/:;,.` / `ABC`

**刷新策略：**
- 密码框区域: 使用 `UPDATE_MODE_DU`（260ms，仅黑白，快速反馈）
- 键盘区域: 仅在切换大小写/数字层时全量刷新
- 使用独立小 Canvas 局部刷新密码框，避免全屏闪烁

### 1.3 连接流程

```
用户点击"连接" →
  显示 "正在连接..." →
  WiFi.begin(ssid, password) →
  等待最多 15 秒 →
    成功: 保存到 /xmnote/wifi.json → 跳转 HOME
    失败: 显示 "连接失败，请检查密码" → 留在键盘页
```

## 二、HTTP 同步服务

### 2.1 API 设计

M5Paper 作为 HTTP Server（端口 80），仅接受局域网请求。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/status` | 设备状态（IP、书摘数量、存储空间） |
| POST | `/api/sync` | 同步书摘数据（全量覆盖） |
| DELETE | `/api/data` | 清空所有书摘数据 |

### 2.2 数据格式

**POST /api/sync** 请求体：

```json
{
  "books": [
    {
      "id": 123,
      "name": "挪威的森林",
      "author": "村上春树"
    }
  ],
  "excerpts": [
    {
      "id": 1001,
      "bookId": 123,
      "content": "每个人都有属于自己的一片森林...",
      "idea": "这段话让我想到了故乡的山林",
      "chapter": "第三章"
    }
  ]
}
```

**GET /api/status** 响应：

```json
{
  "ip": "192.168.1.100",
  "excerptCount": 42,
  "bookCount": 8,
  "sdFreeKB": 15200,
  "version": "1.0.0"
}
```

**字段说明：**
- `books[].id` — 对应 XMNote 的 BookEntity.id
- `books[].name` — 书名
- `books[].author` — 作者
- `excerpts[].id` — 对应 NoteEntity.id
- `excerpts[].bookId` — 关联的书籍 ID
- `excerpts[].content` — 书摘正文（必填）
- `excerpts[].idea` — 个人感想（可选，可为空字符串）
- `excerpts[].chapter` — 章节名（可选）

### 2.3 同步策略

- **全量覆盖**：每次 sync 替换全部数据，简单可靠
- App 端负责筛选哪些书摘推送到设备
- M5Paper 收到数据后写入 SD 卡，屏幕闪烁提示同步完成
- 同步过程中 HOME 页面显示进度

## 三、数据存储

### 3.1 SD 卡目录结构

```
SD 卡根目录
├── font.ttf              ← TTF 中文字体（已有）
└── xmnote/
    ├── wifi.json          ← WiFi 配置
    └── data.json          ← 书籍 + 书摘数据
```

### 3.2 文件格式

**wifi.json：**
```json
{"ssid": "MyHomeNetwork", "password": "12345678"}
```

**data.json：**
与 POST /api/sync 的请求体格式一致，直接存储。

### 3.3 技术选型

- JSON 解析: 添加 `ArduinoJson` 库（成熟、内存友好、支持流式解析）
- 大文件处理: 使用 `DeserializationOption::Filter` 按需解析字段
- 内存: JSON 文档用 `DynamicJsonDocument` 分配到 PSRAM (`ps_malloc`)

- 滑动/按键切换到下一条书摘

## 七、关键技术要点

| 项目 | 方案 |
|------|------|
| HTTP Server | ESP32 内置 `WebServer` 库，端口 80 |
| JSON 解析 | `ArduinoJson` v7，支持流式解析大文件 |
| WiFi 扫描 | `WiFi.scanNetworks()`，按 RSSI 排序 |
| 触摸键盘刷新 | 密码框用独立小 Canvas + `UPDATE_MODE_DU` 局部刷新 |
| 数据存储 | SD 卡 `/xmnote/data.json`，全量读写 |
| 书摘展示 | 按条目翻页，单条超长时复用 getExceedOffset 内部分页 |
| 内存管理 | JSON 文档 + 文本缓冲区用 `ps_malloc` 分配到 PSRAM |
| 颜色 | 0=白, 15=黑, 8=中灰（分隔线/次要文字） |
